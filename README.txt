BACHAL for Android: Start a room / Join a room, no addresses

BUILD
1. Install Android Studio. File > Open > select this folder (Bachal). Let it sync (needs internet once).
   If it offers to upgrade Gradle/Android plugin, accept.
2. Plug in a phone (USB debugging on) and press Run, or Build > Build APK(s).
   The APK is in app/build/outputs/apk/debug/app-debug.apk. Send it to friends and install it.

USE
- One person: open Bachal > "Start a room" > "Open hotspot settings" > turn the hotspot on.
- Everyone else: connect to that hotspot, open Bachal > "Join a room". It finds the room by itself.
- If Android asks "No internet, stay connected?" choose stay connected.

NOTES
- Chat history lives in the host phone's memory and clears when the room stops.
- Some public Wi-Fi networks block phones from seeing each other. A phone hotspot does not.
